# Password Strength Checker
 
## Overview
A Python script that evaluates password strength based on length,
character complexity, and the presence of numbers and special characters.
Demonstrates core security concepts around authentication policy enforcement.
 
## Tools & Technologies
- Python 3
 
## Features
- Checks password length
- Detects presence of numbers
- Evaluates character diversity
- Returns strength rating: Weak / Medium / Strong / Very Strong
- Simulates real-world account lockout logic
 
## How to Run
```bash
python password_checker.py
```
 
## Skills Demonstrated
- Python functions and conditionals
- Security awareness (password policies)
- Input validation
- Authentication concepts
 
## Real-World Application
Password strength checkers are used in:
- Web application registration forms
- Corporate password policy enforcement
- Security auditing tools
