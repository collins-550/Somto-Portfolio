# Python Port Scanner

## Overview
A lightweight Python-based port scanner built using the `socket` library.
Scans a target IP address for open and closed ports and displays results
in a clean, readable format.

## Tools & Technologies
- Python 3
- Socket library (built-in)

## Features
- Scans any target IP address
- Identifies open and closed ports
- Supports custom port ranges
- Clean formatted output

## How to Run
```bash
python scanner.py
